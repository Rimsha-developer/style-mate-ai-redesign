# Style Mate AI — Demo Data Directory

This directory contains reference sample garments and images used for demonstration, automated validation, and offline testing.

## Contents

- `wardrobe/`: 10 sample curated garments covering Tops, Bottoms, Dresses, Outerwear, Shoes, and Bags with canonical slots, occasion tags, and gender classifications.
- `wardrobe/wardrobe_demo.json`: Portable JSON catalog referencing these items with relative asset paths.

## Purpose

These demo items are **not** loaded automatically into a user's personal wardrobe upon clean deployment. They are retained as reference fixtures and test datasets.
